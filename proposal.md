# Proposal: Python Diary App

## Problem
Building a consistent writing habit is often hindered by the friction of opening complex applications or websites. Developers who spend their time in the terminal need a faster way to log daily thoughts.

## Solution
A lightweight Python CLI application that allows users to quickly record diary entries and track their writing consistency through "streaks."

## Scope
- Simple CLI command to add entries.
- Storage of entries in a local JSON file.
- Feature to view past entries.
- Basic streak tracking (days in a row with at least one entry).

## Out of Scope
- Cloud synchronization.
- Rich text formatting.
- Encryption (V1).

## Success Criteria
User can add a diary entry in under 5 seconds from the terminal.
